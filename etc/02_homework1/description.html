Домашна работа 1

Домашно HTML

Курс: Web технологии, летен семестър 2025/2026  |  СИ

Цел: Да се затвърдят знанията за структуриране на съдържание чрез HTML. В тази задача ще създадете многостраничен уебсайт, използвайки само HTML.

📋 Описание

Създайте уебсайт от минимум 5 HTML страници по реална тема по ваш избор. Примери: исторически личности, филми, спортни отбори, книги, видео игри, градове, музикални групи и др. Целият текст трябва да бъде изцяло на български език.

📁 Структура на уебсайта

Вашият проект трябва да съдържа следните файлове:

index.html Начална страница — въведение в темата
about.html Подробна информация по темата
timeline.html Хронология — минимум 5 събития с дати
data.html Страница с таблица с данни
contact.html Страница с формуляр за контакт

✅ Изисквания

1. Семантична структура

Всяка страница трябва да използва семантичните елементи: <header>, <nav>, <main>, <section>, <footer>. Навигацията (<nav>) трябва да свързва всички страници помежду им.

2. Текстови елементи

В уебсайта използвайте поне по веднъж текстови елементи. Например: <blockquote>, <abbr>, <cite>, <time datetime="...">, <mark>, <strong>, <em> или др.

3. Списъци

Използвайте и трите типа списъци: <ul>, <ol> и <dl> (списък с дефиниции).

4. Медия

Добавете изображения с alt атрибут, поне една <figure> с <figcaption>. (Можете и  по един <audio> или <video> елемент с controls).

5. Таблица (data.html)

Създайте таблица с <caption>, <thead>, <tbody>, <tfoot> — минимум 4 колони и 5 реда данни.

6. Формуляр (contact.html)

Формулярът трябва да съдържа: <fieldset> с <legend>, <label> за всяко поле, минимум 5 различни input типа (text, email, number, date, radio/checkbox), <textarea>, <select> и бутон за изпращане. Формулярът не трябва реално да работи.

7. Вътрешна навигация

На поне една страница добавете навигация с линкове към раздели в същата страница чрез id атрибути и href="#...".

🚫 Забрани

  • НЕ използвайте CSS (<style>, style="", .css файлове)
  • НЕ използвайте JavaScript (<script>, onclick="")
  • НЕ използвайте остарели тагове (<center>, <font>, <b>, <i>) — използвайте <strong> и <em>

💡 Достъпност и качество на кода

  • Всяка страница има уникален <title> и <meta charset="UTF-8">
  • Всички изображения имат alt атрибут
  • Заглавията (<h1>–<h6>) следват логическа йерархия
  • Проверете кода с validator.w3.org

📦 Файлова структура и предаване

[ФН]_[Име]_[Фамилия]_HTML/
├── index.html
├── about.html
├── timeline.html
├── data.html
├── contact.html
├── images/
├── media/
└── README.txt

README.txt трябва да съдържа: вашето име и ФН, избраната тема, кратко описание и източници на изображения/медия.

Компресирайте папката в ZIP архив и качете в Moodle.

Папката, ZIP архивът и всички файлове трябва да следват точно следната конвенция:

Папка [ФН]_[Име]_[Фамилия]_HTML/
ZIP архив [ФН]_[Име]_[Фамилия]_HTML.zip
