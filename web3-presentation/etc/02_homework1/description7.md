Create a website of minimum 5 HTML pages on a topic "The Rotary Non Governmental Organization".

Website Structure

Your project must contain the following files:

index.html

Homepage — introduction to the topic

about.html

Detailed information on the topic

timeline.html

Timeline — minimum 5 events with dates

data.html

Data table page

contact.html

Contact form page

Requirements

1\. Semantic structure

Each page must use the semantic elements: header, nav, main, section, footer. Navigation (nav) must connect all pages to each other.

2\. Text elements

Use text elements at least once on your website. For example: blockquote, abbr, cite, time datetime="...", mark, strong, em or others.

3\. Lists

Use all three types of lists: ul, ol and dl (definition list).

4\. Media

Addimages with alt attribute, at least one figure with figcaption. (You can also one audio or video element with controls).

5\. Table (data.html)

Create a table with caption, thead, tbody, tfoot — minimum 4 columns and 5 rows of data.

6\. Form (contact.html)

The form must contain: fieldset with legend, label for each field, at least 5 different input types (text, email, number, date, radio/checkbox), textarea, select and a submit button. The form does not have to actually work.

7\. Internal Navigation

On at least one page, add navigation with links to sections within the same page using id attributes and href="#...".

Prohibit

*   DO NOT use CSS (style, style="", .css files)
*   DO use JavaScript (script, onclick="")
*   DO NOT use deprecated tags (center, font, b, i) — use strong and em

Accessibility and Code Quality

*   Each page has a unique title and meta charset="UTF-8"
*   All images have an alt attribute
*   Headings (h1–h6) follow a logical hierarchy
