`index.html` - clientside:

```plaintext
<p>Upload a file:</p>
<form id = "fileForm">
  <input type="file" id="myFile" name="filename">
  <input type="submit" id="sendFileButton">
</form>

<script>
    addEventListener("DOMContentLoaded", () => {
        const form = document.getElementById("fileForm");
        form.addEventListener("submit", function(event){
            event.preventDefault();

            const formData = new FormData(form);

            fetch("./handle_file.php", {
                method: 'post',
                body: formData
            });
        })
    });
</script>
```

`handle_file.php` - serverside:

```plaintext
<?php

//1 how to fetch information from file:
$loc = $_FILES["filename"]["tmp_name"]; // any file location you want to open, in this case we open users' file
$jsonData = file_get_contents($loc);
var_dump($jsonData); // literal content of file
$arrayData = json_decode($jsonData, true); // true param is for array output, instead of stdClass' object.
var_dump($arrayData);



//2 save file to server.
$destination_location = "path/file.extension"; // where to save permanently
if(move_uploaded_file($_FILES["filename"]['tmp_name'], $destination_location))
  echo "OK";
else
  echo "DID NOT WORK";
?> 
```
